An exact address (/about) matches only that page. * matches within one part of the address (/blog/*); ** matches any depth (/docs/**).
When two wildcard patterns both match an address, the one with the longer fixed part wins; priority breaks a further tie.
Overrides

Custom meta tags
Anything not covered above — Facebook’s fb:pages, a verification tag, or whatever a platform asks for next.
Extra structured data (JSON-LD)
Added alongside what the page already emits — a FAQPage or HowTo block for answer engines, a Product/Review schema, anything schema.org defines. A JSON array of objects; leave as [] for none.
