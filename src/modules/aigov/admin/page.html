Routing: which model answers which task

Privacy: if the first model fails, or its answer fails the check, the same request is sent to the next one. A "local, then Claude" route can therefore send the same text to Claude that the local model already saw. A task with a route never quietly uses the default model: if no model on its route can answer, it stops with an error.
