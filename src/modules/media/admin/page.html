Media

Images, videos and documents. Images get a private copy without camera data and smaller sizes.
Image processing isn't installed on this server, so images can't be uploaded. Run npm install without --omit=optional.
Video thumbnails need ffmpeg on the server. Videos still upload, without a thumbnail.
Images will be stored exactly as uploaded, including camera data such as location. You can compress them later.
