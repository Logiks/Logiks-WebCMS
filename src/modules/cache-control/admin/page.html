Cache

Clear what the servers keep so a change shows at once, or switch server-side caching off while you develop.

Server-side caching is off. Every page and API answer is built on each request, and nothing is kept by browsers or a CDN. Turn it back on before the site goes live.
Server-side caching
Applies to every server at once and takes effect immediately. While it is off nothing is stored or served from the cache (rendered pages, content and API answers), and responses are sent so browsers and CDNs do not keep them either. Compiled templates need no switch: they are rebuilt whenever a file changes.
Clear

Each button clears on every server. Visitors and the admin get fresh copies on their next request; nothing is deleted from the site itself.

Rendered pages
Every page the site has built and kept. Use after editing content, a menu or a setting.
Templates and components
The compiled site (pages, components, styles) on each server, and the pages built from it. Use after changing a component or layout.
Everything
All of the above, plus content and API data, and a re-read of themes and libraries. The surest reset.
