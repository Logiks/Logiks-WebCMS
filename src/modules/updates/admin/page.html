Updates

Pull the latest code from git and restart servers. Every server keeps its own copy of the code, so update them one at a time and the load balancer keeps the others serving.

Restart makes the process exit, so it must run under systemd, PM2 or Docker with a restart policy, or it stays down. Restart starts a new copy of the process by itself. Under a supervisor, set the restart method in Settings.
Update source
Every update is pulled from here. Applies to every server, and each server needs read access to the repository. Defaults to the official Logiks-WebCMS repository.
