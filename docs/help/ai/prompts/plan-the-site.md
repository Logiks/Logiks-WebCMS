Read the requirements document and the current site map, then propose a plan for [[the site or section to build]].

Give me, compactly:

1. The pages and what each one is for (address, purpose, the action it drives).
2. The shared components (header, footer, cards, forms) and which existing components you will reuse.
3. The content types and Services the pages need, and where the data comes from.
4. The design direction in two sentences, and the design tokens you will set once.
5. The build order.
6. Everything that will be sample content because only I can supply it.

Show it with propose_plan and stop. Build nothing until I approve.
