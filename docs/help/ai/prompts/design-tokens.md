Set the visual identity of the site once, in the theme, as CSS variables: [[brand colours and mood]].
Define: ink, muted, line, bg, soft, accent (with a readable hover state), a type scale with one heading font and one body font (installed locally from System → Libraries, no CDN), spacing and radius.
Check every colour pair for 4.5:1 contrast for text. Then show me three existing pages at 375 px and desktop to confirm they pick the tokens up. Change no content.
