Review the site before launch. Check and report, without changing anything:
content (placeholder text, typos, missing alt text, empty pages); navigation (every menu link works, 404 exists); forms (contact form works end to end); SEO (titles, descriptions, canonical,
noindex only where intended, sitemap and robots); accessibility (contrast, headings, focus, labels); mobile (375 px) and tablet; performance (large images, blocking scripts); security (no external sources,
maintenance mode off, noindex setting off); languages.
Give a table: issue, where, severity (blocker / should fix / nice to have), suggested fix. Then ask which to fix.
