Improve the contact page.
Turn the contact form on (Settings → Website) if it is off and check messages appear under System → Messages.
Show: the form (name, email, message) with clear success and error states, our details ([[address, phone, email, opening hours]]), and how long we usually take to reply ([[time]]).
No embedded third-party maps or scripts (the site's security policy blocks them); give directions in words and a link to [[map link]].
Mark up the organisation's details as LocalBusiness structured data through an SEO Manager rule for /contact.
