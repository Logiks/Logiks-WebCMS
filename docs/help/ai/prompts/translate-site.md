Add [[language]] ([[code]]) to the site. Turn on Multiple languages if it is off, then translate the site's strings from the default language with a [[formal / informal]] register.
Keep brand names and product names untranslated. List the strings you were unsure about so a native speaker can check them; leave them marked AI until someone has.
Then show me the home page and one long page in [[language]] and point out text that overflows or breaks the layout.
